# 任务说明（Task）

## 1. 环境：FrozenLake-v1（Gymnasium）

一个 4×4 的冰湖地图：

```
S F F F        S：起点（Start）
F H F H        F：冰面（Frozen），可以走
F F F H        H：冰洞（Hole），掉进去这局结束，奖励 0
H F F G        G：终点（Goal），到达后这局结束，奖励 1
```

- **状态**：agent 所在格子的编号 $s \in \lbrace 0, 1, \cdots, 15 \rbrace$ ，按行编号（左上角是 0，右下角是 15）。
- **动作**： $a \in \lbrace 0, 1, 2, 3 \rbrace$ ，分别对应 左、下、右、上。
- **奖励**：只有到达 G 时得 1，其他情况都是 0（**稀疏奖励**）。
- **转移**：`is_slippery=True` 时冰面会打滑，执行一个动作后，往意图方向走的概率是 1/3，往两侧垂直方向各 1/3。所以即使策略最优，也不能保证每局都到达终点。
- **回合结束**：掉进 H、到达 G，或者走满 100 步（截断）。

## 2. 要做的事

在**不知道转移概率 $p$** 的前提下，只通过和环境交互，用 Q-learning 学出一张 $16 \times 4$ 的 Q 表 $Q(s, a)$ ，然后用贪心策略

$$
\pi(s) = \arg\max_{a} Q(s, a)
$$

尽可能多地从 S 走到 G。

## 3. 验收标准

| 设置 | 目标 |
|---|---|
| `is_slippery=False`（确定性） | 贪心策略成功率 100% |
| `is_slippery=True`（打滑，默认） | 贪心策略成功率约 70% 以上（理论最优约 74%） |

另外要能说清楚：
1. Q 表里每个格子的箭头（最优动作）为什么指向那个方向，比如打滑时 agent 会故意"背对"冰洞走；
2. 训练曲线（成功率随回合数变化）为什么先低后高。

## 4. 输出

运行 `python main.py` 后，在 `outputs/` 下生成：
- `task.png`：任务示意图（地图与状态编号、4 个动作、打滑转移概率）
- `episode.gif`：用学到的贪心策略跑一局的动画（agent 位置、轨迹、每步动作）
- `q_table.npy`：训练好的 Q 表
- `training_curve.png`：滑动平均成功率 + ε 衰减曲线
- `policy.png`：地图上每个格子的贪心动作箭头 + 状态价值 $V(s) = \max_a Q(s, a)$ 热力图
