# Q-learning 前置概念（Basic）

本文件把 Q-learning 用到的四个核心概念讲清楚：**MDP → 贝尔曼方程 → TD 更新 → ε-greedy**。
每个概念按 **定义 + 公式 + 含义（衡量了什么）** 记录。回报 $U_t$ 、 $Q_\pi$ 、 $V_\pi$ 的定义见 [Note/基础概念/04-价值函数.md](../../Note/基础概念/04-价值函数.md)。

---

## 1. 马尔可夫决策过程（Markov Decision Process, MDP）

- **定义**：描述"agent 与环境交互"的数学框架，由五元组组成：

$$
\mathcal{M} = (\mathcal{S}, \mathcal{A}, p, r, \gamma)
$$

| 符号 | 名称 | 在 FrozenLake 4×4 中 |
|---|---|---|
| $\mathcal{S}$ | 状态空间 | 16 个格子，编号 0–15 |
| $\mathcal{A}$ | 动作空间 | 4 个动作：0 左、1 下、2 右、3 上 |
| $p(s' \mid s, a)$ | 状态转移概率 | 冰面打滑：往意图方向走的概率 1/3，往两侧垂直方向各 1/3 |
| $r(s, a, s')$ | 奖励 | 到达终点 G 得 1，其余都是 0 |
| $\gamma \in [0, 1]$ | 折扣率 | 代码里取 0.99 |

- **马尔可夫性（Markov property）**：

$$
p(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \cdots, s_1, a_1) = p(s_{t+1} \mid s_t, a_t)
$$

- **含义**：下一个状态只取决于**当前**状态和动作，与更早的历史无关。所以 agent 只需看当前状态 $s_t$ 做决策，价值函数也只需写成 $Q(s, a)$ ，不用把整段历史带进去。
- **有模型 vs 无模型**：如果 $p$ 和 $r$ 已知，可以直接用动态规划（值迭代）算出最优解；**Q-learning 是无模型（model-free）方法**，它不知道 $p$ ，只能靠和环境交互得到的样本 $(s_t, a_t, r_t, s_{t+1})$ 来学习。

---

## 2. 最优动作价值函数（Optimal Action-Value Function） $Q^\star$

- **定义**：在所有策略中，取能让 $Q_\pi$ 最大的那个：

$$
Q^\star(s, a) = \max_{\pi} Q_\pi(s, a)
$$

- **由 $Q^\star$ 得到最优策略**：

$$
\pi^\star(s) = \arg\max_{a} Q^\star(s, a)
$$

- **含义**： $Q^\star(s, a)$ 衡量"在状态 $s$ 做动作 $a$ ，之后**都按最优方式**行动，平均能拿到多少折扣回报"。只要知道了 $Q^\star$ ，每一步选 Q 值最大的动作就是最优决策。**Q-learning 的目标就是学出 $Q^\star$。**

---

## 3. 贝尔曼方程（Bellman Equation）

### 3.1 回报的递推关系

$$
U_t = R_t + \gamma U_{t+1}
$$

- **含义**：从 $t$ 开始的回报 = 这一步的奖励 + 折扣后的"从 $t+1$ 开始的回报"。贝尔曼方程就是对这个式子两边取期望。

### 3.2 贝尔曼期望方程（针对某个策略 $\pi$）

$$
Q_\pi(s_t, a_t) = \mathbb E_{S_{t+1}, A_{t+1}} \left[ R_t + \gamma Q_\pi(S_{t+1}, A_{t+1}) \mid S_t = s_t, A_t = a_t \right]
$$

- **含义**：当前 $(s, a)$ 的价值 = 即时奖励 + 下一个 $(s', a')$ 价值的折扣期望。 $a'$ 是按策略 $\pi$ 选的。

### 3.3 贝尔曼最优方程（Bellman Optimality Equation）

$$
Q^\star(s_t, a_t) = \mathbb E_{S_{t+1} \sim p(\cdot \mid s_t, a_t)} \left[ R_t + \gamma \max_{a'} Q^\star(S_{t+1}, a') \right]
$$

- **定义**：把 3.2 中"按 $\pi$ 选 $a'$"换成"选最好的 $a'$"，得到 $Q^\star$ 满足的方程。
- **含义**：最优 Q 值等于"即时奖励 + 下一状态里**最好动作**的最优 Q 值"的期望。它是一个**自洽条件**：真正的 $Q^\star$ 代进去，等号两边相等；不对的 Q 代进去，两边就有差距。Q-learning 就是不断缩小这个差距。
- **终止状态**：如果 $s_{t+1}$ 是终止状态（掉进洞 H 或到达终点 G），之后没有回报，所以 $\max_{a'} Q^\star(s_{t+1}, a') = 0$ 。

---

## 4. 时序差分更新（Temporal Difference, TD）

贝尔曼最优方程里有期望 $\mathbb E$ ，但我们不知道 $p$ ，没法直接算。解决办法是**用一个样本代替期望**（见 [采样估计](../../Note/RL中的数值计算/)）。

### 4.1 TD 目标（TD target）

观测到一条转移 $(s_t, a_t, r_t, s_{t+1})$ 后：

$$
y_t = r_t + \gamma \max_{a} Q(s_{t+1}, a)
$$

- **含义**： $y_t$ 是对 $Q^\star(s_t, a_t)$ 的一个估计。它比当前的 $Q(s_t, a_t)$ **更可靠**，因为里面有一部分 $r_t$ 是真实观测到的奖励。

### 4.2 TD 误差（TD error）

$$
\delta_t = y_t - Q(s_t, a_t)
$$

- **含义**：衡量"当前估计"和"多看一步后的估计"差多少。 $\delta_t > 0$ 说明 $Q(s_t, a_t)$ 估低了， $\delta_t < 0$ 说明估高了。学好以后， $\delta_t$ 的期望趋近于 0（也就是满足贝尔曼最优方程）。

### 4.3 TD 更新（Q-learning 更新规则）

$$
Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \cdot \delta_t
$$

- $\alpha \in (0, 1]$ 是**学习率**。
- **含义**：把 $Q(s_t, a_t)$ 往 TD 目标 $y_t$ 的方向挪一小步。等价写法是 $Q \leftarrow (1-\alpha) Q + \alpha y_t$ ，即旧估计和新估计的加权平均。
- **为什么叫"时序差分"**：它利用相邻两个时刻 $t$ 和 $t+1$ 的价值估计之差来学习，不用等整局结束（这一点和蒙特卡罗方法不同），走一步就能更新一次。
- **自举（bootstrapping）**：TD 目标里用到了 $Q$ 自己的估计 $Q(s_{t+1}, \cdot)$ ，即"用估计去更新估计"。

## 5. ε-greedy 探索策略（ε-greedy Exploration）

- **定义**：训练时以概率 $\epsilon$ 随机选动作（**探索**），以概率 $1-\epsilon$ 选当前 Q 值最大的动作（**利用**）：

$$
a_t =
\begin{cases}
\text{均匀随机选一个动作} & \text{概率 } \epsilon \\
\arg\max_{a} Q(s_t, a) & \text{概率 } 1 - \epsilon
\end{cases}
$$

- **含义**：解决**探索与利用的权衡（exploration vs exploitation）**。
  - 只利用（ $\epsilon = 0$ ）：一开始 Q 表全是 0，agent 永远选同一个动作，可能根本走不到终点，也就永远拿不到奖励、学不到东西。
  - 只探索（ $\epsilon = 1$ ）：一直乱走，学到的知识用不上。
- **ε 衰减（decay）**：训练初期 Q 表不可信，多探索；后期 Q 表变准，多利用。代码中用指数衰减：

$$
\epsilon_k = \max(\epsilon_{\min}, \ \epsilon_0 \cdot d^k)
$$

  其中 $k$ 是回合（episode）编号， $d$ 是衰减系数。
- **测试 / 预测时**：不再探索，直接用贪心策略 $\arg\max_a Q(s, a)$ 。

---

## 6. 把四个概念串起来

```
MDP：给出问题（状态、动作、转移、奖励、折扣）
  └─ 目标：学到 Q*，然后用 argmax 选动作
       └─ 贝尔曼最优方程：Q* 必须满足的等式（含期望，无法直接算）
            └─ TD 更新：用一个样本代替期望，一步一步逼近 Q*
                 └─ ε-greedy：决定用哪个动作去产生样本，保证所有 (s, a) 都被访问到
```

## 符号表

| 符号 | 含义 |
|---|---|
| $s, s'$ | 当前状态、下一状态 |
| $a, a'$ | 当前动作、下一动作 |
| $r_t$ | 第 $t$ 步得到的奖励 |
| $\gamma$ | 折扣率 |
| $\alpha$ | 学习率 |
| $\epsilon$ | 探索概率 |
| $Q(s, a)$ | Q 表中的估计值 |
| $Q^\star(s, a)$ | 最优动作价值函数 |
| $y_t$ | TD 目标 |
| $\delta_t$ | TD 误差 |
