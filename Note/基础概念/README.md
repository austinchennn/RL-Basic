## 记号约定

- **大写字母**（$S, A, R, U$）表示**随机变量**，即还没发生、取值未知的量。
- **小写字母**（$s, a, r, u$）表示**观测值**，即已经发生、取值已知的量。
- 下标 $t$ 表示时刻；$n$ 表示回合结束的时刻。

## 符号速查

| 符号 | 名称 | 一句话含义 |
|---|---|---|
| $s$ | 状态 State | 当前局面 |
| $a$ | 动作 Action | agent 做出的选择 |
| $r$ | 奖励 Reward | 做完一步动作后环境给出的即时反馈 |
| $\pi(a \mid s)$ | 策略 Policy | 在状态 $s$ 下选择动作 $a$ 的概率 |
| $p(s' \mid s, a)$ | 状态转移 State Transition | 在 $s$ 做 $a$ 后环境转到 $s'$ 的概率 |
| $\gamma$ | 折扣率 Discount factor | 未来奖励打几折 |
| $U_t$ | （折扣）回报 Return | 从 $t$ 时刻起到结束的累计（折扣）奖励 |
| $Q_\pi(s, a)$ | 动作价值函数 | 在 $s$ 做 $a$、之后按 $\pi$ 行动，期望能拿多少回报 |
| $V_\pi(s)$ | 状态价值函数 | 在 $s$ 按 $\pi$ 行动，期望能拿多少回报 |
| $Q^\star(s, a)$ | 最优动作价值函数 | 在 $s$ 做 $a$，最好能期望拿多少回报（$\max_\pi Q_\pi$） |

## 一张图串起来

```
            π(·|s_t)            p(·|s_t, a_t)
 … ──▶ s_t ─────────▶ a_t ───────────────────▶ s_{t+1} ─────────▶ a_{t+1} ──▶ …
                               同时给出 r_t
       └── agent 决策 ──┘  └──────── 环境响应 ────────┘
```

- 动作的随机性来自**策略** $\pi$（agent）
- 状态的随机性来自**状态转移** $p$（环境）
- 两者叠加，使奖励 $R_t$ 和回报 $U_t$ 都成为随机变量，所以要用**期望**（价值函数）来评价好坏。
