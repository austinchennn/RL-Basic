# 01 基本术语（Terminologies）

课件全程用**超级马里奥**做例子：马里奥是 agent，游戏程序是 environment。

---

## 1. 智能体（Agent）

- **定义**：做出动作的主体，根据观测到的状态做决策。
- **例子**：被控制的马里奥。
- **含义**：强化学习要学的就是 agent 的行为方式，也就是策略 $\pi$。

## 2. 环境（Environment）

- **定义**：agent 与之交互的外部世界。它接收 agent 的动作，返回新的状态和奖励。
- **例子**：游戏程序本身。
- **含义**：环境决定"做了某个动作之后会发生什么"。它内部的规则（状态转移 $p$、奖励规则）通常对 agent 是未知的。

## 3. 状态（State）$s$

- **定义**：对当前局面的描述，agent 根据它做决策。
- **例子**：马里奥游戏中**当前这一帧画面**。
- **含义**：状态是 agent 做决策时能用的全部信息。

## 4. 动作（Action）$a$

- **定义**：agent 在当前状态下做出的决策。
- **公式**：

$$
a \in \mathcal{A}, \qquad \text{例如 } \mathcal{A} = \lbrace \text{left}, \text{right}, \text{up} \rbrace
$$

  $\mathcal{A}$ 称为**动作空间**。
- **含义**：动作是 agent 影响环境的唯一途径。动作空间可以是**离散**的（左/右/上），也可以是**连续**的（如方向盘角度）。这一点决定了后面 $V_\pi$ 是用求和还是用积分来算。

## 5. 策略（Policy）$\pi$

- **定义**：策略函数。输入状态 $s$，输出所有动作的概率分布；agent 从这个分布中**随机抽样**出要执行的动作。
- **公式**：

$$
\pi : (s, a) \mapsto [0, 1], \qquad \pi(a \mid s) = \mathbb{P}(A = a \mid S = s)
$$

  且满足 $\sum_{a \in \mathcal{A}} \pi(a \mid s) = 1$。
- **例子**：观测到状态 $s$ 后，

$$
\pi(\text{left} \mid s) = 0.2, \quad \pi(\text{right} \mid s) = 0.1, \quad \pi(\text{up} \mid s) = 0.7
$$

  agent 按这个概率抽一个动作。所以**观测到 $S = s$ 后，动作 $A$ 仍然可以是随机的**。
- **含义（衡量了什么）**：$\pi(a \mid s)$ 表示在状态 $s$ 下 agent 有多倾向于选动作 $a$。强化学习的目标就是学到一个好的 $\pi$。

### 随机策略 vs 确定性策略

- **确定性策略**：给定 $s$，总是输出同一个动作（某个动作的概率为 1）。
- **随机策略**：给定 $s$，按概率抽动作。
- **为什么需要随机**：课件用"石头剪刀布"举例。如果策略是确定的，对手很快就能猜到你出什么并针对你；只有随机出拳才不会被利用。所以本课程中的策略一般是随机策略。

## 6. 奖励（Reward）$R$

- **定义**：agent 执行一个动作后，环境给出的**标量反馈**。
- **例子**（马里奥）：

| 事件 | 奖励 |
|---|---|
| 吃到一个金币 | $R = +1$ |
| 赢得游戏 | $R = +10000$ |
| 碰到 Goomba（游戏结束） | $R = -10000$ |
| 什么都没发生 | $R = 0$ |

- **含义**：奖励定义了任务目标。奖励数值的相对大小体现了优先级：赢游戏（+10000）远比吃金币（+1）重要，碰到敌人则是严重惩罚。奖励设计得好不好，直接影响 agent 最终学到什么。
- **下标约定**：本课程中，$R_t$ 由 $S_t$ 和 $A_t$ 决定，即在 $s_t$ 执行 $a_t$ 后拿到 $r_t$。（Sutton & Barto 教材把同一个奖励记为 $R_{t+1}$，对照阅读时注意下标差 1。）

## 7. 状态转移（State Transition）$p$

- **定义**：agent 在旧状态 $s$ 下执行动作 $a$ 后，环境变成新状态 $s'$。

```
           action
old state ────────▶ new state
```

- **公式**：

$$
p(s' \mid s, a) = \mathbb{P}(S' = s' \mid S = s, A = a)
$$

- **例子**：马里奥执行 "up" 后进入新状态。但新状态不一定唯一，比如敌人 Goomba 的移动是随机的，可能以 0.8 的概率是一种局面、0.2 的概率是另一种局面。
- **含义（衡量了什么）**：$p(s' \mid s, a)$ 描述**环境的动态规律**，也就是在 $s$ 做 $a$ 后转到 $s'$ 的可能性有多大。
  - 状态转移**可以是随机的**。
  - 这种随机性**来自环境**，不由 agent 控制。
  - 通常只有环境（游戏程序）知道 $p$，agent 不知道。
