# 02 随机性与交互（Randomness & Agent-Environment Interaction）

---

## 1. 两种随机性来源（Two Sources of Randomness）

| 来源 | 公式 | 由谁产生 | 例子 |
|---|---|---|---|
| **动作的随机性** | $A \sim \pi(\cdot \mid s)$ | 策略函数（agent） | 给定 $s$，以 0.2 / 0.1 / 0.7 的概率选 left / right / up |
| **状态的随机性** | $S' \sim p(\cdot \mid s, a)$ | 状态转移函数（环境） | 给定 $s, a$，以 0.8 / 0.2 的概率转到两个不同的新状态 |

- **含义**：
  - 给定状态 $s$，agent 的动作是从 $\pi(\cdot \mid s)$ 中**抽样**得到的。
  - 给定 $(s, a)$，环境的新状态是从 $p(\cdot \mid s, a)$ 中**抽样**得到的。
  - 因为有这两层随机性，后面的奖励、回报都是**随机变量**，所以需要用**期望**（价值函数）来评价好坏。

## 2. 智能体与环境的交互（Agent-Environment Interaction）

```
                ┌─────────┐
     ┌─────────▶│  Agent  │──────────┐
     │          └─────────┘          │
  state s_{t+1}                   action a_t
  reward r_t                         │
     │       ┌───────────────┐       │
     └───────│  Environment  │◀──────┘
             └───────────────┘
```

每个时刻 $t$：

1. agent **观测**状态 $s_t$；
2. 按策略**抽样**动作 $a_t \sim \pi(\cdot \mid s_t)$，并**执行** $a_t$；
3. 环境返回**新状态** $s_{t+1}$ 和**奖励** $r_t$。

然后不断重复：

```
s_1 ─▶ a_1 ─▶ s_2 ─▶ a_2 ─▶ s_3 ─▶ a_3 ─▶ s_4 ─▶ ⋯
              r_1           r_2           r_3
```

---

## 3. 轨迹（Trajectory）

- **定义**：交互过程中产生的 (state, action, reward) 序列。
- **公式**：

$$
s_1, a_1, r_1,\ s_2, a_2, r_2,\ \cdots,\ s_n, a_n, r_n
$$

- **含义**：轨迹记录了一局游戏中实际发生的全部事情，也是 agent 学习时用的原始数据。

## 4. 回合（Episode）

- **定义**：从游戏开始到游戏结束（马里奥赢了或死了）的整个过程，称为一个 episode。
- **含义**：$n$ 就是一个回合的结束时刻。一条轨迹通常对应一个完整的回合。

## 5. 什么是好的策略？

- 好的策略能带来**大的累计奖励**：

$$
\sum_{t=1}^{n} \gamma^{t-1} \cdot r_t
$$

- 用奖励来**引导**策略的学习。
