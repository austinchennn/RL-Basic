# 采样估计（Sampling / Monte Carlo）

蒙特卡罗积分（Monte Carlo Integration）的核心思想很直观：**用随机抽样的平均值，代替复杂的积分计算**。

当函数形状太复杂、积分无法用笔算出解析解时，蒙特卡罗方法可以用计算机模拟来近似求解。

---

## 1. 核心数学原理

假设要计算函数 $f(x)$ 在概率密度函数 $p(x)$ 下的期望（也就是一个积分）：

$$
I = \int f(x) p(x) \ dx = \mathbb{E}_{X \sim p}\left[ f(X) \right]
$$

这个积分本质上就是随机变量 $f(X)$ 的数学期望 $\mathbb{E}[f(X)]$。根据**大数定律**，当样本数量足够多时，样本的算术平均会收敛到真实期望。

计算步骤：

1. **独立抽样**：从分布 $p(x)$ 中随机抽取 $N$ 个样本点 $x_1, x_2, \dots, x_N$。
2. **代入求值**：把这 $N$ 个样本代入函数，得到 $f(x_1), f(x_2), \dots, f(x_N)$。
3. **计算均值**：用这组函数值的算术平均作为积分的近似：

$$
\hat{I}_N = \frac{1}{N} \sum_{i=1}^{N} f(x_i)
$$

只要 $N$ 足够大， $\hat{I}_N$ 就会非常接近真实的积分值 $I$。

### 估计量的性质

- **无偏**： $\mathbb{E}[\hat{I}_N] = I$，平均来看估计是准的。
- **方差**： $\mathrm{Var}[\hat{I}_N] = \dfrac{\sigma^2}{N}$，其中 $\sigma^2 = \mathrm{Var}[f(X)]$。
- **误差量级**：标准差为 $\dfrac{\sigma}{\sqrt{N}}$，即误差 $\sim O(1/\sqrt{N})$。样本数变成 4 倍，误差减半。这个速率和 $x$ 的维度无关，第 3 节"维度诅咒"一条依据的就是这一点。

---

## 2. 回到强化学习：用蒙特卡罗估计 $V_\pi(s)$

连续动作空间下，状态价值函数是一个积分（见 [04-价值函数.md](../基础概念/04-价值函数.md)）：

$$
V_\pi(s) = \int \pi(a \mid s) \cdot Q_\pi(s, a) \ da
$$

它和第 1 节的形式一一对应：

| 通用蒙特卡罗 | 强化学习 |
|---|---|
| 概率密度 $p(x)$ | 策略 $\pi(a \mid s)$：本身就是一个概率密度（如高斯分布），给出状态 $s$ 下各动作的概率 |
| 被积函数 $f(x)$ | 动作价值函数 $Q_\pi(s, a)$ |
| 样本 $x_i$ | 从策略中抽出的动作 $a^{(i)}$ |

具体做法：

1. 让 agent 按当前策略 $\pi(a \mid s)$ 随机抽 $N$ 个动作： $a^{(1)}, a^{(2)}, \dots, a^{(N)}$。
2. 把这 $N$ 个动作分别输入 $Q$ 网络，得到 $Q_\pi(s, a^{(1)}), \dots, Q_\pi(s, a^{(N)})$。
3. 求平均，得到 $V_\pi(s)$ 的近似：

$$
V_\pi(s) \approx \frac{1}{N} \sum_{i=1}^{N} Q_\pi\big(s, a^{(i)}\big), \qquad a^{(i)} \sim \pi(\cdot \mid s)
$$

### 另一处蒙特卡罗：用观测回报 $u_t$ 估计 $Q_\pi$

$Q_\pi(s_t, a_t) = \mathbb{E}[U_t \mid S_t = s_t, A_t = a_t]$ 本身也是期望。玩完一局后得到的观测回报 $u_t$（见 [03-回报.md](../基础概念/03-回报.md)），就是 $U_t$ 的**一个样本**。所以 $u_t$ 本身就是 $Q_\pi(s_t, a_t)$ 的 $N = 1$ 的蒙特卡罗估计：无偏，但方差大。

### 小实验

玩具设定：策略 $\pi(a \mid s) = \mathcal{N}(0, 0.5^2)$， $Q(s, a) = -(a - 1)^2$。这时解析解为 $V = -\left[(\mu - 1)^2 + \sigma^2\right] = -1.25$。

```python
import numpy as np

rng = np.random.default_rng(0)

mu, sigma = 0.0, 0.5
Q = lambda a: -(a - 1.0) ** 2
V_true = -((mu - 1.0) ** 2 + sigma ** 2)   # -1.25

for N in [10, 100, 10_000, 1_000_000]:
    a = rng.normal(mu, sigma, size=N)       # 1. 按策略抽 N 个动作
    V_hat = Q(a).mean()                     # 2-3. 代入 Q 并取平均
    print(f"N={N:>9,}  V_hat={V_hat:.4f}  误差={abs(V_hat - V_true):.4f}")
```

输出：

```
N=       10  V_hat=-1.0545  误差=0.1955
N=      100  V_hat=-1.1949  误差=0.0551
N=   10,000  V_hat=-1.2446  误差=0.0054
N=1,000,000  V_hat=-1.2495  误差=0.0005
```

$N$ 每增大 100 倍，误差大约缩小 10 倍，符合 $O(1/\sqrt{N})$。

---

## 3. 为什么强化学习偏爱蒙特卡罗采样？

- **维度诅咒（Curse of Dimensionality）**：传统数值积分（如梯形公式、辛普森积分）在高维时计算量随维度**指数级爆炸**。蒙特卡罗的收敛速度 $O(1/\sqrt{N})$ 与维度无关，因此适合高维的动作 / 状态空间和深度神经网络。
- **无需知道环境全貌**：很多 RL 任务中，我们根本不知道环境的数学模型（状态转移 $p$ 和奖励函数的具体公式），但可以通过**与环境交互、采样**拿到数据。所以蒙特卡罗方法在**无模型（model-free）**算法中被大量使用。

---

## 延伸方向

- 采样之后怎么对策略参数**求梯度**：对数似然技巧（log-derivative trick / REINFORCE）和重参数化技巧（reparameterization trick），在 PPO、SAC 等算法中使用。
